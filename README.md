# 2D Game

### Links:

- https://git-huber123.itch.io/2d-game - itch.io page
- https://git-huber123.github.io/2d-game/ - github page
- https://github.com/git-huber123/2d-game - github repo

### Features:

- You can move around
- There are walls
- There are enemies
- You can place and break blocks
- Enemies have intelligent pathfinding, instead of just randomly walking towards you like my other games
- There's an inventory system

### Known bugs:

##### Not fixed:

- None at the moment!

##### Fixed:

- The enemies can get stuck in each other, even though I have a checkEnemyCollisions() function.

### Work in progress:

- None as of now.

### Planned:

### AI Usage Disclamer:

I used AI to help me with some debugging, as well as helping me with some of the more complex helper functions, such as the hash function (uses some weird bitwise math), hslToRgb() (no clue how to do that), and some of the other ones too. However, most of the game is written by me. The functions written by AI are wrapped in a comment block noting that they are AI-written.
